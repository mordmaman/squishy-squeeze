# Squishy Squeeze

A squishy squeezing game — squeeze, collect sparkles, unlock new squishies.

**Play it:** https://mordmaman.github.io/squishy-squeeze/

## How to play

- **Squeeze the squishy** (tap, click or press Space) to earn ✨ sparkles. It squashes and slowly rises back.
- **Helpers** squeeze for you, even when you're not tapping: Hamster, Bunny, Robot, Factory, Cloud Machine, Rainbow Slide, Squishy Planet and Sparkle Galaxy. Each one costs a bit more than the last.
- **Upgrades** make squeezes and helpers twice as strong.
- **New squishies** unlock as you earn more: Mochi, Strawberry Bun, Kitty, Cloudy, Peachy, Panda, Glitter Cake and Rainbow Unicorn. Each one makes squeezes worth more.
- **Golden sparkles** 🌟 pop up now and then — tap fast for a lucky bonus or a Sparkle Frenzy.
- **Trophies** for big milestones.

Progress saves automatically on each device, and helpers keep earning (at half speed, up to 8 hours) while you're away.

On a phone or tablet, install it from the browser menu (**Add to Home screen** / **Install app**) to get an app icon and play offline.

## Changing the game

Everything is in `index.html`. Near the top of the script:

- `CONFIG` — title, how fast prices rise, frenzy strength
- `SQUISHIES` — names, colours, how much each is worth and when it unlocks
- `HELPERS` — names, emoji, prices and how many sparkles each makes

Commit a change and GitHub Pages updates the game in a minute or so.
